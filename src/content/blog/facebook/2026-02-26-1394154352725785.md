今年我選修了恩師戴文凱教授的《網頁遊戲引擎原理與實作》。

這堂課的核心目標：

用 Cocos Creator，從零開始學會打造「可以真正發布」的網頁遊戲。

我從小就想做一款屬於自己的遊戲。

一不小心繼續念博士班，改往學術界走，又忽然轉身跟一群夥伴創業，開始寫 RQ 跑力；然後桐桐就出生了。

各種時間跟現實考量，這個夢想就被我暫存起來。

這學期剛好修了這門課，我決定趁這次機會，一邊上課，一邊把那個遊戲的雛形做出來。

工具鏈今天裝好了，夢想正式 commit 第一個版本。

有些人 40 歲開始練馬拉松。\
有些人 40 歲重返博士班。

我要當那個——

40 歲還想做遊戲的工程師。

這學期，我會把它生出來的！

等我 Demo 喔。

📌 第一週課程主軸筆記

一、課程介紹與教學計劃\
二、Cocos Creator 簡介與安裝\
三、JavaScript / TypeScript 環境建置\
四、開發工具鏈完整安裝流程

教授跟助教群第一堂課就帶大家把整個開發環境從頭裝好：

✔ Cocos Dashboard\
✔ Node.js + npm\
✔ TypeScript\
✔ VSCode\
✔ Git\
✔ GitHub Desktop\
✔ Prettier\
✔ ESLint

特別強調幾件事：\
 • Cocos Creator 2 和 3 有大量 breaking changes（要抄 code的話，版本一定要看清楚）\
 • 3.x 版本以 TypeScript 為主\
 • Coding style 要統一（Prettier + ESLint 直接配好）\
 • 專案要從第一天就用 Git 版本控制
